
# ITAI‑2373 – Natural Language Processing Labs

This directory contains the lab assignments for **ITAI‑2373: Natural Language Processing**.  
Each lab focuses on a core NLP concept, combining theory with hands‑on implementation using modern NLP tools and machine learning techniques.

---

## Labs Included

### **Lab 02 – Text Preprocessing & Tokenization**
Focuses on foundational NLP preprocessing steps such as:
- Cleaning and normalizing text  
- Tokenization  
- Stop‑word removal  
- Stemming and lemmatization  
- Bag‑of‑Words and TF‑IDF representations  

### **Lab 04 – Word Embeddings & Semantic Similarity**
Covers distributed word representations and semantic modeling:
- Word2Vec, GloVe, or similar embeddings  
- Vector arithmetic  
- Cosine similarity  
- Semantic clustering and visualization  

### **Lab 05 – Text Classification**
Applies machine learning models to classify text:
- Feature extraction (TF‑IDF, embeddings)  
- Training classifiers (Naive Bayes, Logistic Regression, SVM, etc.)  
- Evaluating accuracy, precision, recall, and F1‑score

### ** Lab 07 – Sentiment and Emotion Analysis in the Real World**
The process of computationally identifying and categorizing emotions, opinions, and attitudes expressed in text and speech.
